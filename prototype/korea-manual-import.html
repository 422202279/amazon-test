韩国站人工采集

在没有卖家 API 账号前，先用人工采集 + 模板导入维持韩国站产品主档和重点评论样本

采集模式：人工采集
推荐频次：每周 1~2 次
视频只保留封面图 + 原链接

采集步骤

先建产品主档，再补重点评论和证据，不追求一次性全量抓完

1. 打开买家页面按店铺或产品链接查看公开页面
2. 记录主档标题、链接、价格、评分、评论数、内部 SKU
3. 补重点差评只录重点差评样本、图片证据、视频封面
4. 导入模板用标准表格导入，保留“人工采集”来源标记

建议保留字段

优先保留最有价值、最容易持续更新的字段

产品主档平台、店铺、标题、产品链接、价格、评分、评论数、内部 SKU
评论样本星级、评论时间、评论内容、问题分类、封面图链接、原评论链接
来源标记人工采集 / 页面校验 / 手动导入
更新备注本次更新时间、操作人、是否完整采集
