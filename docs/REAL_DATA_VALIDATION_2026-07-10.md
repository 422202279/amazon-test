- 179 条内部 Amazon Listing：ASIN、原始标题、产品链接 100% 有值；近30天销量在各店覆盖 48% 到 100%；评分/评论总数在绝大多数记录有值。

- 当前没有一份真实“逐条评论”导出，因此评论总表、差评归因和供应商整改不能宣称已用真实评论验证。

## 已发现的阻断

1. 现有导入器会把店铺页中的名称（例如“加拿大”）和产品导出中的名称（例如“Petmo”）创建为不同店铺；同类问题也出现在“日本站/日本店”。这导致 10 个店铺页记录导入后变为 18 条店铺注册表记录，不能直接作为多店铺对比的正式主数据。
2. 法国、Coupang、Naver 缺少真实产品明细来源；不能使用演示记录补齐。
3. 公开商品页直连被平台安全策略拦截，浏览器自动化连接也未成功建立稳定会话。因此公开页抓取不作为正式数据来源，也不能作为云端主链路。

## 下一步数据前置条件

在修改同款组、店铺身份和多店铺对比前，需要补齐以下真实来源之一：

1. 法国店、Coupang、Naver 的产品明细 Excel 导出，或对应卖家侧官方 API 权限。
2. 至少一份 Amazon 逐条评论导出，用于验证评论、整改任务和问题分类闭环。
3. 加拿大产品导出对应的真实店铺标识，确认 `Petmo` 是否就是“加拿大”店铺，避免错误合并。

在这些来源补齐前，系统只能对上述 188 条真实 Listing 做导入和接口验证，不能说“11 个店铺的真实数据已全部验证”。
