# 字段可得性验证矩阵

更新时间：2026-07-03

这份表不是理论判断，是基于你现有 Excel、卖家精灵导出样本、以及 2026-07-03 的抽样请求结果整理的。

## 一、先给结论

- 产品主档：可以做，而且优先走 Excel 导入最稳
- 产品核心指标：Amazon 可以“导入为主 + 页面低频校验”
- 评论明细：V1 不建议承诺全自动稳定抓取
- 韩国站：`Coupang / Naver` 都不适合作为云端高频自动抓取主链路

## 二、按平台判断

| 平台 | 抽样结果 | 可持续性 | 适合做主来源的数据 |
| --- | --- | --- | --- |
| Amazon US / UK / DE / JP | 商品页可直连返回 `200`，可抽到标题、ASIN、评分、评论数、主图、类目等 | 中高 | 产品主档、评分摘要、Review 总数、页面校验 |
| Amazon 评论页 | 直连返回不稳定，部分站点 `SSL EOF`，返回页里未稳定出现评论块 | 中低 | 只适合低频尝试，不适合当唯一来源 |
| Coupang 商品页 | 商品详情直连 `403 Access Denied` | 低 | 不适合作为云端定时主链路 |
| Coupang 店铺页 | 店铺页 `200`，但更像前端壳页面，商品列表非直出 | 中低 | 可做人审入口，不建议依赖批量自动抓取 |
| Naver 商品页 / 店铺页 | 直连 `429` | 低 | 不适合作为云端定时主链路 |

## 四、这次样本验证到了什么

### Amazon 商品页

实测样本：

- 美国：`B0FMRB4Z21`
- 英国：`B0FP4JG5TD`
- 德国：`B0F9YJF121`
- 日本：`B09YCY71C4`

抽样确认可直接解析到：

- 标题
- ASIN
- 评分
- 评论数
- 面包屑类目
- 卖点 bullet
- 主图

附加说明：

- 美国样本页里价格位有时没有直接出现在首个解析节点里，说明价格字段要允许页面校验失败后回落到导入值
- 日本评论页与评论详情抓取存在 `SSL EOF` 波动，不能把它当成稳定接口

### Coupang

实测样本：

- 商品页：`https://www.coupang.com/vp/products/8818842450?vendorItemId=92688007302`
- 店铺页：`https://shop.coupang.com/petmoment/317768?...`

结果：

- 商品页直连返回 `403`
- 店铺页返回 `200`
- 但店铺页不是“后端直接把完整商品列表写进 HTML”的结构，更像前端动态加载

判断：

- 云端最低配服务器不适合把 Coupang 作为高频自动化主来源
- 更适合：
  - 维护店铺页链接
  - 人工低频核查
  - 后续有条件再补浏览器自动化

### Naver

实测样本：

- 商品页：`https://smartstore.naver.com/petmoment-kr/products/12176956328`
- 全店产品页：`https://smartstore.naver.com/petmoment-kr/category/30UuXxUJCDpixkR43xc7p_ALL_PRODUCT?cp=1`

结果：

- 两个链接直连都返回 `429`

判断：

- 不适合作为云端定时主链路
- V1 应优先设计成：
  - 店铺与产品列表手动导入
  - 页面链接留存
  - 少量重点商品人工复核

## 五、对系统设计的直接影响

### V1 推荐主链路

1. 产品数据：
   - 内部总表导入
   - 卖家精灵产品表导入
   - 卖家精灵历史销量/销售额/价格表导入
2. 评论数据：
   - 先支持人工导入
   - 再加低频自动补抓任务
3. 页面校验：
   - 只校验少量重点 SKU
   - 不做全量高频抓取

### 不建议在 V1 承诺的能力

- 所有平台评论明细每天全自动抓全
- 韩国站完整评论图片稳定抓取
- 仅靠公开页面就自动生成完整、准确的评论数据库

## 六、原型字段调整建议

产品总表建议保留并支持显隐的字段：

- 产品
- 店铺 / 站点
- 平台
- 父ASIN
- 类目
- 价格
- 近30天销量
- 近30天销售额
- Review 总数
- 月新增评分数
- 评分
- 变体数
- BSR
- 配送方式
- 跟卖卖家
- BuyBox 状态
- BuyBox 卖家
- A+ / 视频 / 广告标记
- 上架时间
- 新增差评
- 主要差评原因
- 供应商
- 整改状态

评论总表保留当前设计方向即可，但数据来源必须标识：

- 导入
- 页面补抓
- 人工修正
